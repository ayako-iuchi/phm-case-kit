# Changelog

Revisions are dated and kept visible. Nothing is changed silently.

## Kit v1.0 — 2026-10-28

- First release of tools. Added `tools/pages.py`, `tools/quotecheck.py`, `tools/termcount.py`, `tests/test_tools.py`, `evidence/quotecheck_inventory_2026-10-28.txt`, `evidence/quotecheck_inventory_2026-10-28.tsv`, `CHANGELOG.md` and `CITATION.cff`. Standard library only.
- `quotecheck.py` generalizes the check the author ran on 28 October 2026 on an inventory of the source written by a separate agent: each quotation, with all whitespace removed, must be on the page given for it. It adds what that check did not report: duplicates, short quotations, quotations found on more than one page, quotations equal to a whole line, and a self-test that alters each quotation four ways. `termcount.py` counts where a term occurs, page by page.
- The evidence files record the run on the inventory's 350 quotation rows: 350 OK, 347 distinct, 44 of 10 characters or fewer, 15 on more than one page, 48 equal to a whole line; the self-test catches 349 of 349 replacements and deletions in the middle, and 0 of 349 shortenings at either end. They hold no quotation text. The earlier check dropped only lines starting with `https://note.com/kompas`; `--note-footer` drops lines starting with any note.com URL, and gives the same result on this source.
- Both READMEs describe the tools, what they do not check, the self-test, the tests and the evidence. The README's series line now says "from Blog #37": on 28 October 2026 the author decided that the technical posts of this theme continue the numbering of Hypothetical Technical Blog (the first is Blog #37), replacing the "PdM #1 / 予兆 #1" numbering in the initial commit.
- A separate agent reviewed the draft (3318cee) on 28 October 2026. Two faults are fixed: the quotes TSV was read with CSV quoting, so a quotation starting with a double quotation mark lost it, and a stray one swallowed the rows after it and could end in exit 0 (now read as plain tab-separated text, with a byte-order mark allowed); and the self-test also ran on rows that were not OK, which counted their shortenings as caught (now OK rows only, and the rows left out are counted). Also fixed: a quotation across a page break was reported MISSING (now found, as `11-12`); a bad regular expression or an unwritable evidence file exited 1 with a traceback, and an inline flag with `--note-footer` failed (now exit 2, and each expression is compiled on its own); a quotes file with no rows exited 0 (now exit 2). The docstrings and both READMEs now say that the middle-change counts describe one run, that `--note-footer` also drops a body line that is only a note.com link, that the header lines go whatever they say, and that termcount counts overlapping occurrences and not across a page break. Fourteen tests were added. The real-source numbers and `evidence/quotecheck_inventory_2026-10-28.tsv` are unchanged; the self-test line of the `.txt` now names the rows left out.
- The same agent's fixes were reviewed again on 28 October 2026 (15bddf3). Fixed after that review: a tab inside a quotation silently cut it short (a row whose number of fields differs from the header is now rejected, exit 2, and blank lines are skipped); a quotation found on one page was not also searched across page breaks (now both are listed, and MULTI counts both); a source file with a byte-order mark kept it in its first header line (now read as UTF-8 with an optional mark); the README said `--note-footer` drops a body line "that is only such a link" (it drops any line that starts with one); the entry above said both READMEs describe termcount's overlapping counts and page breaks, which only its docstring did (both READMEs now do); the evidence column `found_on_pages` was undocumented (a page `4`, or a page break `1-2`). Files changed for these two rounds: `tools/pages.py` (`read_pages` takes one expression or a list, each compiled on its own; the source may start with a byte-order mark), `tools/quotecheck.py`, `tools/termcount.py` (docstring), `tests/test_tools.py` (32 tests after the first round, 37 now), `README.md`, `README.ja.md`, `evidence/quotecheck_inventory_2026-10-28.txt` (the self-test line) and this file. The real-source results are unchanged.
- **A draft commit carried third-party files.** On 28 October 2026 a reviewing agent downloaded 17 Python package files (cffconvert and its dependencies, all under open-source licences) into the working folder, and the draft commit e6e4596 on the branch `kit-v1.0` included them. It was pushed, then replaced by cb4de1a, the same change without those files, and the unreleased branch was force-pushed. No branch, tag or release contains the files, but GitHub can still serve the old commit by its hash. They were not source text from the magazine. This entry is the record.
